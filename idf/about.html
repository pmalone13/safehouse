Overview

Ideal Federal Technologies is a US corporation in business to develop and support software applications that extend and enhance Atlassian products; specifically Jira.

Ideal Federal Technologies began in 2015 with the development of Ideal Forms for Jira. Since that time Ideal Forms has been successfully delivering custom applications using Jira as the powerful platform that it is.

In 2020, Atlassian announced the end of life for their Jira Server product. In response to this change, Ideal Federal Technology has taken the following actions:

  • Migrated Ideal Forms for Jira to the Atlassian Cloud
  • Tested Ideal Forms for Data Center - releasing in 3Q21
  • Released Ideal Worklogs for Jira for Cloud
  • Released Ideal Worklogs for Server (Data Center in 3Q21)
Performing the Cloud migration allowed IFT to refactor the Forms infrastructure such that Ideal Forms now provides a powerful framework for rapid application development for the Atlassian Marketplace. Going forward IFT plans on releasing many applications like Ideal Worklogs for Jira in both Atlassian's cloud and Data Center offerings. Please stay tuned for future developments.

Security Policy

top

1. Overview



Ideal Federal Technologies ("IFT") offers through the Atlassian Marketplace software products designed to enhance our customers' use of Jira software including "Ideal Worklogs for Jira" and "Ideal Forms for Jira" (the "IFT Products"). Customer data is collected by or transmitted to IFT for limited purposes only, namely, anonymous website traffic tracking, customer Jira Cloud configurations, and submissions to IFT's support pages. IFT does not permanently store customer data.

2. Architecture



IFT Products are provided through the Atlassian Marketplace via Server or Data Center products running on our customer's own servers ("IFT Server Apps"), or via Cloud products hosted by IFT through the Atlassian Cloud and Amazon Web Services ("IFT Cloud Apps").

IFT uses Amazon Web Services ("AWS") to support its IFT Cloud Apps, providing a secure environment as well as the stability, redundancy and scalability required by our customers.

3. Backups



Daily backups for IFT Cloud Apps are performed and all backup data is encrypted.

4. Security



Only authorized IFT Developers or IFT Support Engineers have access to the AWS platform hosting IFT Cloud Apps to perform system or application support. SSH with certificate access is the only method available for accessing the environment.

Customers are responsible for securing their login information, that of their local Jira instances, and their end-user privacy.

5. Privacy



IFT is committed to protecting its customers' personal information. For more details, please see our Privacy Policy.

6. Reporting Issues/Contact Us



IFT takes any reports of vulnerabilities seriously. If you encounter a security issue with any of our IFT Products or services, or have any questions about IFT's security policies, please contact us at security@idealfed.com.
