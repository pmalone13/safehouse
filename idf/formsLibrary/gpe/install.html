Installation Steps:
Step 1: Install form group:
  1. Download form group - GPE form group
  2. Click "Forms Admin", and upload the form group using "Upload Group".

Step 2: Edit List Form to Set for Your Project:
  1.     Design the GPE List Form
  2.     Expand Fields
  3.     Select the "itemlist" control
  4.     Edit the datasource for your project
  5.     Save and test"
